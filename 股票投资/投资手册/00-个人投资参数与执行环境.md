# 00 - 个人投资参数与执行环境

> 作用：记录 Andre 当前相对稳定的投资条件、交易工具和风险边界。  
> 不记录容易过期的账户余额或每日持仓市值。

## 当前执行环境

| 项目 | 当前情况 |
|---|---|
| 主要券商 | **IBKR**、**CIBC Investor's Edge** |
| 主要现金币种 | **HKD、USD**；另有少量 **CAD** |
| 主要市场 | 美股、港股；ETF 与现金管理工具 |
| IBKR 港股 | 可交易 SEHK 普通股票 |
| IBKR 美股非正常时段 | 支持 Outside RTH（约 04:00–20:00 ET）；符合条件的美股/ETF另有 Overnight（约 20:00–03:50 ET） |
| 执行偏好 | 非正常时段优先限价单；注意流动性与 spread |

> 券商规则、交易时段和费用会变化；实际下单前如有疑问，应重新核对官方资料。

## 风险与投资条件

| 维度 | 当前原则 |
|---|---|
| 风险态度 | 可以承担波动，但不应为了收益承担失控的永久损失风险 |
| 现金 | 现金是安全垫、补仓弹药和未来机会的选择权，不要求满仓 |
| 买入方式 | 偏向研究后的左侧、分批、小仓开始 |
| 周期价值股 | 倾向分散篮子；不靠单票重仓押注 |
| 加仓 | 只有 thesis 仍成立时才加；不能因为跌得多自动补仓 |
| 集中度 | 仓位用于表达确定性；不确定性越高，仓位越小 |
| 行动纪律 | 没有足够安全边际时可以 **No Action** |
| 核心风险观 | 优先防永久损伤、价值陷阱、流动性风险和情绪化交易 |

## 更新原则

只有当这些“长期执行条件”发生变化时更新本页，例如：

- 更换主要券商；
- 可用主要币种发生变化；
- 风险承受边界明显改变；
- 仓位或现金管理原则改变；
- 新增重要市场或账户类型。
