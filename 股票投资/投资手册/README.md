## 这套手册解决什么问题

这套手册记录的是**长期稳定的投资原则、决策框架和执行纪律**，而不是任何单只股票的即时观点。

核心目标：

- 在承担可控风险的前提下实现长期资产增值；
- 区分好公司、好股票、好价格、好仓位和好退出规则；
- 保留现金安全池和未来机会；
- 用周期价值与科技成长两条主线寻找机会；
- 防止价值陷阱、概念炒作、估值过热和情绪化交易；
- 把研究、仓位、退出和复盘变成可重复流程。

## 两条主动选股主线

### 1. 周期型价值股

**低估、周期、修复、不容易死、防价值陷阱。**

核心问题：

> 公司是否只是暂时处于低谷，而不是永久受损？

### 2. 科技成长股

**AI、机器人、量子计算、长期趋势、技术壁垒、商业化能力、防概念炒作、防估值过热。**

核心问题：

> 技术趋势是否真实，公司是否真正占据价值链关键位置，而当前价格是否仍给未来回报留下空间？

## 使用规则

### 当讨论“投资原则”时

优先读取本手册。

### 当讨论某只股票时

先读取本手册中与该股票类型相关的规则，再读取：

`../个股笔记/<股票目录>/`

个股笔记里的结论不能覆盖手册原则。若两者冲突，应明确指出冲突并重新检查 thesis。

### 当市场数据可能变化时

以下内容不能只依赖旧笔记，必须重新核对最新可靠来源：

- 当前股价；
- 市值；
- 财报；
- 指引；
- 估值；
- 新闻；
- 重要股东变化；
- 利率；
- 税务与监管规则。

## 一句话总纲

> **先判断公司会不会永久受损，再判断价格是否有安全边际；用仓位表达不确定性，用退出规则兑现判断。**
