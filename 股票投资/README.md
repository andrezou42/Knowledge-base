# 股票投资

这个目录分成两类内容：

## 1. [投资手册](./投资手册/)

这里保存**长期稳定的投资原则、目标、决策框架和执行纪律**。

当 Andre 说：

- “读一下我们的股票投资手册”
- “先重新看一下我们的投资原则”
- “按我们的投资系统分析一下”

默认先读取这里。

**主入口：** [投资手册 / README](./投资手册/README.md)

---

## 2. [个股笔记](./个股笔记/)

这里保存**具体公司的研究、估值、thesis、交易记录和复盘**。

当 Andre 说：

- “看一下北京机场的 notes”
- “我们之前怎么看小鹏？”
- “读一下 DQ 的投资笔记”

默认查找这里对应股票的 folder。

**个股笔记入口：** [个股笔记 / README](./个股笔记/README.md)

---

## 使用顺序

### 讨论投资方法

`投资手册 → 当前问题`

### 讨论具体股票

`投资手册中的相关原则 → 对应个股笔记 → 最新公开数据 → 当前判断`

### 更新长期原则

只有当新的经验经过复盘、具有可重复性时，才更新投资手册。

### 更新个股判断

只要公司、行业、估值、仓位或 thesis 有重要变化，就更新对应个股笔记。

---

## 核心区分

> **投资手册记录“我们应该怎样思考”；个股笔记记录“我们现在怎么看某家公司”。**

这样即使未来积累几十只甚至上百只股票的研究，也不会污染或冲淡投资原则。
