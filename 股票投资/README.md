## 一句话总纲

**先判断公司会不会永久受损，再判断价格是否有安全边际；用仓位表达不确定性，用退出规则兑现判断。**

Andre 当前主动选股不是纯巴菲特式永久持有，也不是短线交易。主要采用两条主线：

- **周期型价值股：**低位、不容易死、有修复路径、分散等待、修复后卖出。
- **科技成长股：**长期趋势真实、技术壁垒真实、商业化真实、估值不过度透支未来。

同时保留 ETF、现金和房产作为更基础的资产配置部分。股票决策必须服从整体现金安全池、家庭与事业的安全边界。

## 决策时必须区分

- 好公司
- 好股票
- 好价格
- 好仓位
- 好退出 / 复盘规则

即使公司很好，也可能不是好价格；即使价格很好，也不代表适合重仓。

## 信息原则

涉及以下可变事实时，必须查最新可靠来源：

- 当前股价、成交量、市值
- 财报、指引、资产负债表
- 估值
- 新闻与监管
- 利率、税务、法规
- 券商与账户规则

严肃分析应明确区分：**事实、假设、推断、不确定性、不可知部分。**
