- **公司：**Daqo New Energy Corp. / 大全新能源
- **Ticker：**DQ
- **交易所：**NYSE
- **币种：**USD
- **投资类型：**周期价值 / Capital Cycle
- **当前状态：**观察
- **核心定位：**多晶硅行业周期底部候选，尚未确认完成出清

## 1. 当前一句话 thesis

DQ 的核心机会不是预测某个具体催化剂，而是等待多晶硅行业在长期亏损后出现真正的供给退出：**如果价格长期压低导致 CapEx 收缩、高成本产能退出、库存消化，而全球光伏终端需求仍然存在，则供需关系本身可能推动下一轮价格与盈利修复。**

目前更适合定义为：

> **周期底部候选，而不是已经确认的周期底部。**

## 2. 为什么市场可能错

市场可能把当前极差的多晶硅盈利环境线性外推过久，而忽略：

- 长期亏损会主动摧毁供给；
- 行业 CapEx 已经/可能继续明显收缩；
- 高成本产能无法长期在低于成本的价格下运行；
- 光伏长期终端需求并未消失；
- DQ 若拥有较低成本和较强资产负债表，可能比高成本竞争者更有能力熬过出清。

但这一 thesis 只有在**供给真正退出、库存开始下降、需求没有结构性破坏**时才成立。

## 3. Capital Cycle 核心逻辑

> **低价格 → 行业亏损 → 减产 / 停产 / CapEx 收缩 → 供给退出 → 库存消化 → 供需修复 → 价格与利润可能恢复**

不要求提前猜中最终催化剂是什么。

真正要验证的是：

> **Supply destruction + surviving demand**  
> **供给被摧毁 + 需求仍然存在**

## 4. 以后每次讨论 DQ 必查的 5 个指标

### 1. 多晶硅价格 vs DQ 成本

必须重新查：

- 中国多晶硅主流现货价格；
- DQ 最新 cash cost；
- DQ 最新 total production cost；
- 当前价格是否已经稳定高于总成本，而不是短暂反弹。

关键问题：

> **行业价格是否真正回到可持续盈利区？**

### 2. DQ Production vs Sales

必须比较：

- 当季产量；
- 当季销量；
- 连续几个季度的变化。

真正重要的改善信号：

> **Sales ≥ Production，并且不是一次性波动。**

如果长期 production >> sales，说明供给和库存压力仍未解决。

### 3. Inventory

必须检查：

- DQ 库存金额 / 吨数；
- 环比、同比；
- 全行业多晶硅库存；
- 库存是否连续下降。

周期底部确认的重要信号之一：

> **库存从累积转向持续消化。**

### 4. 行业 Utilization / 永久产能退出

必须检查：

- 行业平均开工率；
- 头部与高成本厂商开工率；
- 哪些产能只是暂时检修 / 停产；
- 哪些产能已经永久关闭、破产、转产或退出；
- 是否发生行业整合。

重点：

> **临时减产不等于 supply destruction。真正 bullish 的是高成本供给永久退出。**

### 5. 行业 CapEx 与新增产能

必须检查：

- DQ CapEx；
- 主要竞争者 CapEx；
- 新建多晶硅项目；
- 延期 / 取消项目；
- 新进入者数量。

真正的底部环境通常需要：

> **行业普遍不愿再投新钱，而不是价格一反弹大家马上重新扩产。**

## 5. 辅助确认信号

除上述五项外，每次还应检查：

- 全球及中国光伏新增装机需求；
- 光伏产业链价格与组件需求；
- 中国“反内卷”及产能政策；
- DQ 现金、债务和生存能力；
- 新疆大全（688303）市值及 DQ 持股价值；
- DQ ADR 相对所持子公司价值的 holding-company discount；
- 资金从中国子公司上移至 DQ Cayman 的现实限制；
- UFLPA / 美国贸易政策；
- ADR / 地缘政治 / 治理风险。

## 6. 主要上行逻辑

1. 多晶硅价格长期低于成本，迫使高成本产能退出；
2. 行业 CapEx 大幅减少，新供给下降；
3. 库存逐渐消化；
4. 全球光伏长期需求继续增长；
5. DQ 低成本与强资产负债表使其能够熬过行业出清；
6. 若周期恢复，当前极低估值可能出现盈利修复 + 估值修复双重弹性；
7. DQ 对新疆大全的持股价值可能提供资产层面的估值支撑，但需考虑可兑现性和控股折价。

## 7. 主要风险 / 反方证据

1. **需求结构性下降：**如果光伏需求长期弱于预期，供给退出也未必足够；
2. **假出清：**产能只是暂时停产，价格稍回升就迅速复产；
3. **库存过大：**库存山延长价格低迷时间；
4. **中国行业政策：**政策可能改变价格形成、产能退出或行业竞争方式；
5. **UFLPA / 贸易限制：**新疆相关政策可能造成长期估值折价和市场隔离；
6. **Holding-company discount：**新疆大全资产价值不等于 ADR 股东能直接兑现的价值；
7. **治理 / 资本分配：**子公司与 Cayman 层面的利益、现金流和少数股东结构需持续检查。

## 8. Thesis 失效条件

原周期修复逻辑需要重新评估，如果出现：

- 光伏终端需求出现长期结构性下降；
- 行业低价持续多年但产能仍没有真正退出；
- 库存长期不降反升；
- DQ 成本优势消失；
- DQ 资产负债表显著恶化；
- 新技术使现有多晶硅路线发生永久性替代；
- 政策 / 地缘因素使 DQ 的经济价值长期无法归属于 ADR 股东。

## 9. 买入前的最低确认框架

不要仅因为“价格很低”买入。优先等待以下证据组合中的多数出现：

- 多晶硅价格稳定在合理成本以上；
- DQ sales 接近或超过 production；
- 库存连续下降；
- 行业开工率低且出现永久产能退出；
- CapEx 与新增项目持续收缩；
- 终端需求仍然健康；
- DQ 资产负债表仍足够强。

不要求所有信号同时完美，但必须能够解释：

> **为什么这次是周期底，而不是结构性衰退或又一次短暂反弹。**

## 10. 当前研究结论（2026-09-30）

当前判断：

> **DQ 已进入值得认真研究的周期底部候选区域，但“库存出清”和“供给永久退出”仍是最需要进一步确认的两个关键证据。**

后续讨论 DQ 时，优先更新第 4 节的五个指标，再讨论估值和仓位。
