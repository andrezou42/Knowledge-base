# 个股笔记

这里存放**单只股票的研究资料、投资 thesis、估值、交易记录和复盘**。

这不是投资原则区。任何个股结论都应服从上一级 [股票投资手册](../投资手册/) 的原则。

## 推荐目录命名

优先格式：

`交易所代码-公司简称/`

例如：

- `00694.HK-北京首都机场/`
- `9868.HK-小鹏汽车/`
- `DQ-大全新能源/`
- `ATZ.TO-Aritzia/`

这样比只用中文公司名更容易长期检索，也能避免同名公司混淆。

## 每只股票建议结构

每只股票建立一个独立 folder：

```text
个股笔记/
└── 00694.HK-北京首都机场/
    ├── README.md          # 当前 thesis / 总结 / 最新状态
    ├── 估值.md            # 正常化盈利、情景估值、目标区间
    ├── 时间线.md          # 财报、行业、公司重大事件
    └── 交易与复盘.md      # 买卖、仓位变化、判断对错
```

不需要一开始就把四个文件全部建齐。研究较少时，只用一个 `README.md` 即可；资料变多后再拆分。

## 对话中的默认规则

当 Andre 说：

- “看一下北京机场的 notes”
- “读一下小鹏的投资笔记”
- “我们之前对 DQ 的 thesis 是什么”

优先查找本目录里对应股票 folder。

然后再根据当前问题决定是否需要重新获取最新市场数据。

## 状态标记

建议每只股票 README 顶部保留：

- **Ticker / 交易所**
- **研究类型：**周期价值 / 科技成长 / Compounder / Special Situation
- **状态：**观察 / 已持有 / 减仓中 / 已退出
- **最后更新日期**
- **核心 thesis**
- **主要风险**
- **下一次需要验证的信号**

## 原则

> **个股笔记记录“我们现在怎么看这家公司”；投资手册记录“我们应该怎样思考”。**
