# 家庭养生活

这里保存 Andre 在**信仰、家庭、健康、生活秩序、事业与生意选择**上的长期原则。

它不是股票研究区，也不是日常流水账。只保存会长期影响重大决策的内容。

## 使用规则

当 Andre 讨论以下问题时，优先读取这里：

- 人生方向、信仰、价值排序；
- 家庭与健康是否应优先于赚钱；
- 是否应该进入一个新的事业或生意；
- 是否因焦虑、FOMO、疲惫而做重大决定；
- 某个机会是否破坏长期生活秩序。

股票投资的具体原则仍放在：

`股票投资/投资手册/`

> **家庭养生活定义上位价值与生活边界；股票投资手册定义投资执行规则。**
